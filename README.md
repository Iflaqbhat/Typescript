# TypeScript Learning

Learning TypeScript from basic to advanced, one topic per day.

## How this repo works

- Each day has its own folder: `day-01/`, `day-02/`, ...
- Every topic is a small self-contained file you can run.
- We push after each day's session.

## Commands

```bash
npm run dev day-01/functions.ts   # run a file
npm run typecheck                  # check all files
```

## Rules

- `strict` mode is ON. That's where the real learning happens.
- Never use `any` unless you can justify it in a comment.
- If a type is repeated twice, it becomes an alias or interface.
